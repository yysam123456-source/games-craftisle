# PolyBranch

PolyBranch is a meditative 3D sketch by **Gbatha**, entered in GitHub Game Off 2012 and written in **Processing.js** with jQuery for the page plumbing.

A branch grows forward continuously through a 3D space and you steer each new segment to decide where the structure goes. Left alone it produces branching, tree-like forms; steered deliberately, you can draw letters and shapes in three dimensions. There is no fail state and no score - it is a tool for producing something pleasing, and the screenshot mode lets you keep what you make.

## How to Play

1. Move the mouse to steer the direction of growth.
2. Click to branch a new segment.
3. Let it run to build branching structures.
4. Press the screenshot key to save your creation.

## Controls

- **Mouse move** - steer growth
- **Left click** - branch
- **Arrow keys** - rotate the camera
- **S** - screenshot

## Tips

Commit to a direction for a few segments before steering. Turning every frame produces a tight scribble; holding an angle produces the branching forms the sketch is actually about.
