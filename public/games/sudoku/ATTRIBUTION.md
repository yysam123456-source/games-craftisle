## About

The number placement puzzle on a 9x9 grid. Fill every row, every column and every
3x3 box with the digits 1–9 without repeating. Puzzles are randomly generated
with an adjustable difficulty, errors are detected as you type, and the game
detects the win condition.

1980s under the name *SuDoku* and was popularised internationally by Wayne Gould
in 1997. The rules are not copyrightable and nothing here is derived from any
particular published puzzle set — the grids are generated by the code itself.

## Files included

- `index.html` — the entire game: markup, CSS and JavaScript in one 339-line
  file. No framework, no build step, no bundled dependencies.
- `assets/background.svg` — an 800x450 decorative SVG backdrop

There are **no external requests** — no CDN, no web font, no network dependency of
any kind.

## Modifications made for this self-hosted build
