## About

A claymation-style 3D bilingual (Chinese / English) animal world built with
Three.js. Ten clay animals — lion, giraffe, zebra, elephant, monkey, hippo,
crocodile, snake, bird and fish — plus seven explorer props live on a small
island with an S-shaped river and a bridge.

Tapping an animal plays its reaction (the elephant flaps its ears, the
crocodile opens its jaw, the bird flies a lap) and opens a word card that
speaks the English name, plays the animal call, then the Chinese name. Collected
animals go into the explorer handbook; completing all ten triggers confetti.
A robot guide button walks the route automatically.

## Zero external assets

Every model, texture and sound is generated in code — the animals are sculpted
by a Blender Python script, textures are drawn with a noise algorithm, calls
are synthesised through the Web Audio API, and names are spoken with the
browser's own speech synthesis. The 19 GLB models under `models/` are
pre-generated by upstream, so Blender is not needed to run the game.

## Self-hosting changes

Only one change was needed, in `vite.config.js`:

```js
base: './'
```

Upstream ships a bare Vite config, which emits root-absolute `/assets/...`
URLs. Those 404 once the game is served from `/games/clay-safari/`, so the
build is made relative. No game logic or asset was touched.
