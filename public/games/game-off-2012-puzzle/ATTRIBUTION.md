## About

Zoko is redistributed here verbatim, as a self-hosted build that runs entirely in
your browser from `/games/game-off-2012-puzzle/`.

## Modifications made for this self-hosted build

1. Built from source: the game is CoffeeScript and the entry HTML loads the compiled `js/zoko.js`, which is not committed. Built with the project's own `cake build`.
2. Removed the Typekit webfont CDN script.
