# Mindustry Classic — Open Source Attribution

This directory contains the **Mindustry Classic build 40** web build, self-hosted for offline, first-party browser use.

- **Original game:** Mindustry by Anuken
- **License:** GNU General Public License v3.0 (GPL-3.0)
- **Classic source:** https://github.com/Anuken/Mindustry-Classic
- **Modern source:** https://github.com/Anuken/Mindustry
- **Web build mirror:** https://github.com/minidogg/MindustryClassicMirror

The web build was compiled from Java to JavaScript using the libgdx HTML5 backend and Google Web Toolkit (GWT).
